## cross-model detection patterns

### universal signals (work on all models)

**vocabulary overuse** — documented across all RLHF-trained models:
- `delve`, `tapestry`, `underscore`, `meticulous`, `commendable`, `intricate`, `testament`, `realm`, `pivotal`, `robust`, `vibrant`, `crucial`, `comprehensive`, `seamless`, `leverage`, `utilize`, `synergy`
- "It is important to note that…", "It's worth noting that…"
- "Furthermore," / "Moreover," / "Additionally," at paragraph openings
- "In conclusion," / "To summarize," / "In summary," as closings
- "In today's [fast-paced / digital] world…"
- "This underscores the importance of…"
- "Plays a crucial role" / "Stands as a testament to"

**why:** RLHF annotators systematically preferred these words; reward model internalized it; PPO pushed all generations toward that register (arXiv:2412.11385, arXiv:2508.01930).

**low burstiness** — all instruction-tuned models:
- uniform sentence length distribution (low variance)
- human writing alternates naturally between long/complex and short/punchy sentences
- measurable: sentence std dev for AI text ~2–4 words vs ~5–7 for human writing

**low perplexity** — all models:
- sampled from narrow high-probability token distribution region
- basis for GPTZero, DetectGPT, Binoculars detection

**punctuation hygiene** — all models:
- no typos, no self-corrections, no stray commas, no informal dashes
- absence of these is a strong negative signal for human authorship

### family-level signals

**openai (gpt-3.5-turbo, gpt-4o, gpt-4o-mini, gpt-4-turbo):**
- em dash (—) overuse — "ChatGPT hyphen" phenomenon
- markdown by default (headers, bullets, bold) even in conversational contexts
- "Absolutely!", "Certainly!", "Great question!", "Of course!" as openers
- `delve` / `tapestry` peak frequency here

**openai (gpt-4.5-preview, o3-mini):**
- harder to detect than older GPT family
- o3-mini: NO markdown by default, minimal hedging, STEM vocabulary — reversed signals
- gpt-4.5-preview: reduced sycophancy, conciseness, emotional warmth markers

**google (gemini family):**
- conversational register over academic (uses "sugar" not "glucose")
- "polished neutrality" / Wikipedia-like tone
- burstiness 0.15–0.22 (very tight range, lower than other families)
- stylistic drift absent in long outputs (uniform prose quality across 30+ paragraphs)

**meta llama 2:**
- PPO-RLHF over-optimization → highly sycophantic, heavy safety preambles
- "Of course!", "Certainly!", "I'd be happy to help!", "I should note that…"
- high downtoner use: "somewhat," "slightly," "rather," "fairly"
- SentencePiece 32k tokenizer (vs tiktoken 128k in Llama 3)
- `[INST]`/`<<SYS>>` template artifacts

**meta llama 3:**
- DPO (not PPO) → less sycophantic, less safety-padding
- NO downtoner use (documented measurable difference from Llama 2, arXiv:2510.05136)
- markdown bias: strong unprompted bullet lists, bold headers
- "Delve," "nuanced," "multifaceted," "comprehensive" at high frequency
- tiktoken 128k vocabulary (different tokenization fingerprint from Llama 2)

**mistral/mixtral:**
- DPO → lower sycophancy, less RLHF over-alignment than OpenAI/Llama 2
- direct and terse (Mistral-7B), more verbose/conversational (Mixtral)
- no system prompt support natively (`[INST]`/`[/INST]` format)
- **CRITICAL: Mixtral is hardest to classify — 65% of texts unattributable by standard ensemble (arXiv:2503.01659)**

**deepseek-r1-distill:**
- `<think>...</think>` visible chain-of-thought — single strongest fingerprint in entire dataset
- two-phase burstiness: high in `<think>` block, low in final answer
- `\boxed{answer}` for math — near-unique artifact
- 74.2% of outputs classified as OpenAI-generated by standard ensemble → creates false positives for OpenAI detectors

### hardest detection cases (ranked)

1. **gpt-4-turbo-paraphrase / gemini-pro-paraphrase** — post-processed obfuscation. vocabulary features fail; only structural/discourse features survive.
2. **gpt-4.5-preview** — designed for human-likeness; attenuated vocabulary fingerprint; concise
3. **o3-mini** — no markdown, minimal hedging, STEM vocabulary — reversed signals
4. **mixtral-8x7b** — 65% unattributable by standard classifier ensemble; needs Mixtral-specific training
5. **deepseek-r1-distill** — misclassified as OpenAI; think-block stripping hides primary fingerprint
6. **gemini-2.0-flash** — concise by default; harder on short samples
7. **gemini-1.5-pro** — harder than 1.0 Pro due to better instruction following of style prompts

### detection strategy by signal type

| signal type | best targets | survives paraphrase? |
|---|---|---|
| vocabulary frequency (delve, tapestry, etc) | OpenAI GPT family, Llama 3 | No — first to go |
| em dash frequency | GPT-4o, GPT-4-turbo | Partially |
| safety/sycophancy phrases | Llama 2, GPT-3.5, GPT-4-turbo | Partially |
| downtoner frequency | Llama 2 (high) vs Llama 3 (low) | Partially |
| burstiness (sentence length std dev) | all models | Yes — robust |
| punctuation hygiene | all models | Yes — robust |
| POS bigram distributions | all models | Yes — robust |
| discourse structure (intro→body→conclusion) | all models | Yes — robust |
| `<think>` tag | deepseek-r1-distill only | Only if not stripped |
| `\boxed{}` in math | deepseek-r1-distill only | Yes |
| markdown frequency | GPT-4o, GPT-4-turbo, Llama 3 | Partially |
| markdown ABSENCE | o3-mini | Yes |
| per-token surprisal (perplexity) | all models | No — degraded by paraphrase |
| tokenizer artifacts (32k vs 128k vs 150k vocab) | Llama 2 vs 3, Mistral vs Ministral | Partially |
| identity artifacts ("As Falcon3 from TII") | falcon3-10b only | Partially |

### new features to implement based on this research

1. **downtoner rate** — frequency of "somewhat," "slightly," "rather," "fairly," "quite" — distinguishes Llama 2 from Llama 3
2. **em dash frequency** — direct OpenAI GPT-4o signal
3. **sycophantic opener detection** — regex for "Absolutely!", "Certainly!", "Of course!", "Great question!"
4. **safety preamble detection** — "As an AI language model," "I should note that," "It's important to emphasize"
5. **think-block detector** — presence/absence and length of `<think>...</think>` tags
6. **boxed answer detector** — `\boxed{` pattern (deepseek-r1 family)
7. **markdown density** — fraction of lines that are markdown (headers, bullets, bold) — high for GPT-4o/Llama 3, zero for o3-mini
8. **paragraph-level burstiness** — variance at paragraph length level in addition to sentence level
9. **vocabulary ABSENCE features** — fraction of sentences without any of the universal RLHF overuse words
10. **positive valence ratio** — fraction of sentiment-scored tokens with positive valence (AI text skews positive)
